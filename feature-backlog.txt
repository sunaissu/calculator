calculator feature backlog
12 October 2026

Scope and status

This is the implementation contract for all 27 candidate features in this package's existing backlog. OPEN and PARTIAL entries are unfinished work. An implementation plan is not evidence that a feature has shipped. Each entry below gives concrete work, dependencies and acceptance checks. No entry is complete merely because an API type, toolbar button or passing smoke test exists.

Current review

Added bounded equation solving with residual/iteration diagnostics, range and tolerance controls, history replay and exported result metadata.

This pass completes significant-figure formatting and makes history restore the original variable source, captured Ans, angle mode, format and calculus inputs. Invalid intermediate arithmetic now fails immediately, and numerical derivatives validate the function at the requested point. It does not add an error estimate or make numerical calculus exact.

Suggested implementation order

1. Finish the scalar workflow: CAL-04, CAL-16, CAL-19, CAL-20 and CAL-27. CAL-13 is implemented.
2. Add quantities and exploration: CAL-02, CAL-05, CAL-14, CAL-01, CAL-03, CAL-06, CAL-18 and CAL-21.
3. Add data and numeric domains: CAL-07 through CAL-12, CAL-15, CAL-22 and CAL-25.
4. Build advanced math and teaching after their prerequisites: CAL-17, CAL-23, CAL-24 and CAL-26.

Package boundaries

The calculator owns mathematical evaluation and versioned calculation definitions. The document editor and Noteboard own their editing, rendering, serialization and undo behavior. The host owns storage, authentication, authorization, synchronization providers and permission-aware resolution of linked content. Cross-package dependencies use the existing CAL/DOC/NBD identifiers. Keep host callbacks optional and report async failures without losing local work.

Definition of done

For each feature, complete the public types, working UI or documented engine API, serialization/migration when needed, history/read-only behavior, error states, README example and the acceptance checks below. Add a regression that fails before a bug fix. Test user outcomes rather than mirroring private helpers. Mark IMPLEMENTED only after the relevant checks pass and list any host prerequisite.

Release checks

Run npm test, npm run playground:build and npm pack --dry-run --json. Inspect CJS, ESM, declaration files and every README-linked package file in the tarball. Run the documented browser suites for changed workflows, including keyboard and narrow light/dark layouts. Audit root and playground dependency trees. Record exact commands and results in implementation-review.txt.

For shared-schema changes, back up authoritative state, document migration and rollback, test old-data import, and prevent incompatible clients from reconnecting. Provider authentication, durable persistence and reconnect behavior require a host integration test; in-memory Yjs tests do not certify them.

Feature contracts

CAL-01 Graphing
Status: OPEN
Dependencies: CAL-05, CAL-14.
Implementation: Add a bounded sampling API and SVG graph with pan, zoom, trace, root and intersection overlays. Break paths at invalid samples.
Acceptance: Check poles, empty domains, keyboard trace, zoom limits, and intersections against known functions.

CAL-02 Units
Status: OPEN
Dependencies: None.
Implementation: Represent a quantity as magnitude plus dimension exponents; define conversion tables and a quantity expression evaluator alongside the scalar API.
Acceptance: Reject incompatible addition; test compound units, prefixes, affine temperatures, serialization, and conversion roundtrips.

CAL-03 Notebooks
Status: OPEN
Dependencies: CAL-27.
Implementation: Add versioned session import/export and host load/save callbacks, names, history search, and dirty-state controls. Keep storage optional.
Acceptance: Reload a session with variables, units and formats intact; reject invalid or oversized imports; retain edits after save failure.

CAL-04 Dependent variables
Status: PARTIAL
Dependencies: None.
Implementation: Keep ordered assignments, add per-row errors and explicit dependency evaluation on edits without overwriting Ans or appending history.
Acceptance: Changing an input updates dependent outputs; invalid references and cycles produce visible errors; editing never duplicates history.

CAL-05 Equation solving
Status: IMPLEMENTED
Dependencies: None.
Implementation: solveEquation uses bounded bisection, reports residual/iterations, and throws on invalid brackets, nonfinite evaluations or nonconvergence. Engineering UI exposes bounds/tolerance; history and result payloads retain them.
Acceptance: Unit and Chrome checks cover known roots, multiple roots, flat roots, absent sign changes, endpoints, poles, invalid tolerances and exhausted budgets. Residual tolerance does not bound x error; the host supplies a continuous real function.

CAL-06 Formula library
Status: OPEN
Dependencies: CAL-27.
Implementation: Define formula records with names, descriptions, typed inputs and examples; add search and insert controls.
Acceptance: Every bundled example has an expected result and units; user formulas cannot execute JavaScript.

CAL-07 Statistics
Status: OPEN
Dependencies: None.
Implementation: Parse bounded tabular numeric input; expose summary statistics, a documented percentile convention and histogram bins.
Acceptance: Check empty and singleton data, invalid rows, overflow and constant data; chart bins account for every accepted sample.

CAL-08 Regression
Status: OPEN
Dependencies: CAL-07.
Implementation: Add linear and polynomial fits with residuals, rank checks and bounded model complexity.
Acceptance: Check known datasets, singular input, outliers and residual plots; do not show a successful fit for rank-deficient data.

CAL-09 Matrices and vectors
Status: OPEN
Dependencies: None.
Implementation: Add dimension-checked array operations and a keyboard-editable grid; use pivoting for linear systems.
Acceptance: Check mismatched dimensions, singular systems, transpose, inverse residuals and paste validation.

CAL-10 Complex values
Status: OPEN
Dependencies: None.
Implementation: Introduce an explicit complex result type and arithmetic with documented branch conventions, rectangular and polar display.
Acceptance: Check conjugates, angle modes, zero division and branch cuts without breaking the scalar API.

CAL-11 Exact fractions
Status: OPEN
Dependencies: None.
Implementation: Add bounded BigInt rational arithmetic with reduction, exact input parsing and tagged decimal approximations.
Acceptance: Check large denominators, sign normalization and operation limits; never label floating-point approximations as exact.

CAL-12 Programmer mode
Status: OPEN
Dependencies: None.
Implementation: Add BigInt parsing and operations with explicit radix, signedness and word width.
Acceptance: Verify wraparound, shifts and signed display at each supported width; reject out-of-range shift counts and invalid digits.

CAL-13 Result formatting
Status: IMPLEMENTED
Dependencies: None.
Implementation: Implemented in this review: auto, fixed, scientific, engineering and significant notation, with matching UI precision limits.
Acceptance: Unit tests cover rounding and trailing zeroes; browser checks cover significant figures and restored history formats.

CAL-14 Parameter sweeps
Status: OPEN
Dependencies: None.
Implementation: Expose bounded sample tables with a named varying parameter, start/end/count and invalid-sample diagnostics; share them with graphing.
Acceptance: Check endpoints, reversed ranges, maximum sample count and domain errors; support CSV export without formula injection.

CAL-15 Expression explanation
Status: OPEN
Dependencies: None.
Implementation: Refactor parsing into a typed expression tree and instrument evaluated nodes with inputs, operations and intermediate values.
Acceptance: The final traced value equals ordinary evaluation; unsupported syntax is rejected and no invented algebraic proof is displayed.

CAL-16 Numerical accuracy
Status: OPEN
Dependencies: CAL-15 optional.
Implementation: Add adaptive integration and derivative estimates with absolute/relative tolerances, evaluation budgets and convergence status. Keep existing numeric-returning APIs compatible.
Acceptance: Test smooth functions, nonfinite samples, discontinuities, sharp peaks, cancellation and budget exhaustion; label estimated error as an estimate.

CAL-17 Symbolic subset
Status: OPEN
Dependencies: CAL-15, CAL-11.
Implementation: Define a documented expression subset, expression-tree rewrites and symbolic derivative/integral rules with explicit unsupported results.
Acceptance: Verify identities on valid domains and symbolic derivatives numerically; preserve domain restrictions such as x/x at zero.

CAL-18 Worksheets
Status: OPEN
Dependencies: CAL-04, CAL-27.
Implementation: Model stable row IDs and an acyclic dependency graph; add row editing, references and downstream recalculation.
Acceptance: Reordering rows preserves references; cycles and deleted references are visible; changing one row updates only its dependents.

CAL-19 Named memory
Status: PARTIAL
Dependencies: None.
Implementation: Extend the session memory model with a bounded named register collection and select, rename, store and delete controls.
Acceptance: MC/MR/M+/M- retain their behavior; duplicate names, overflow and deleting the active register are covered.

CAL-20 Clipboard blocks
Status: PARTIAL
Dependencies: None.
Implementation: Keep plain result/equation copy; add escaped text/html clipboard blocks with a plain-text fallback.
Acceptance: Paste into a rich editor and plain textarea; reject markup injection and show clipboard-denial feedback.

CAL-21 Scenarios
Status: OPEN
Dependencies: CAL-04, CAL-27.
Implementation: Store named variable overrides against one formula and render a comparison table with per-scenario errors.
Acceptance: Editing one scenario leaves others unchanged; units and formats match; invalid scenarios do not hide valid results.

CAL-22 Host functions
Status: OPEN
Dependencies: CAL-15.
Implementation: Add an explicit registry for trusted host callbacks and constants, including arity and collision checks. Do not parse executable code.
Acceptance: Reject inherited names, name collisions, wrong arity and nonfinite callback returns; document that synchronous host callbacks are trusted code.

CAL-23 Exercises
Status: OPEN
Dependencies: CAL-06, CAL-15.
Implementation: Use authored exercise records with deterministic generation seeds, accepted-answer rules and reviewed worked solutions.
Acceptance: Each difficulty has reproducible examples; grading tolerances and unit requirements are tested independently of the answer display.

CAL-24 Uncertainty
Status: OPEN
Dependencies: CAL-02, CAL-15.
Implementation: Define interval-valued inputs and supported interval operations; show bounds and unsupported propagation clearly.
Acceptance: Check domain crossings, dependency overestimation and outward rounding; do not equate an interval with a confidence level.

CAL-25 Constants catalog
Status: OPEN
Dependencies: CAL-02, CAL-22.
Implementation: Add searchable constant records with dimension, value, source, edition and exact/estimated status; allow host-owned entries.
Acceptance: Every bundled constant has a cited source and units; overrides cannot silently change built-in expression constants.

CAL-26 Probability
Status: OPEN
Dependencies: CAL-07.
Implementation: Implement a documented set of distributions with parameter validation, PDF/PMF, CDF and inverse CDF plus shaded plots.
Acceptance: Compare known values and tail cases; verify probability mass and CDF/quantile roundtrips within stated tolerances.

CAL-27 Live calculation payloads
Status: PARTIAL
Dependencies: CAL-02 for units.
Implementation: Version a serializable calculation definition independently of the displayed result; add validate, reopen and recalculate APIs and a controlled editor seed.
Acceptance: Expression, variables, captured Ans, angle mode, units, format and calculus bounds survive save/reopen; unsupported versions fail explicitly.
