Calculator implementation review
11 October 2026

Implemented a compact variable panel, result formatting, memory, copy controls, and richer result context. Fixed prototype-inherited variable lookup, ambiguous adjacent numeric tokens, stale calculus results when inputs/operation change, and duplicate calculus heading IDs. Automatic notation disables the unused decimal-place control; inserted results retain the displayed format in their metadata.

Validation: npm test passes 5 tests (including the smoke suite); type check, CJS/ESM/type builds, playground build, and package dry-run pass. Runtime npm audit reports 0 vulnerabilities. Chrome checks cover dependent variables, display formatting, memory, and light/dark layouts at desktop and 390-pixel width.

Release status: locally validated changes, not published. Numerical calculus still has no convergence estimate or accuracy controls; this is not a claim that all mathematical edge cases or feature requests are complete.
